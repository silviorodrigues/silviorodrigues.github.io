- Reference the deleted multi-page site via `git show b5e4821:<path>` for old conventions/copy — e.g. `src/components/header.tsx`, `src/components/footer.tsx`, `src/data/projects.ts` (SVG icon/logo path data), `src/app/globals.css` (`.linear-wipe`/`shine` gradient text).
- Stack is Next.js 16 (App Router) + React 19, not the old repo's Next 14/React 18 — chose current versions to avoid the ~5 high-severity CVEs in Next 14.2.35/postcss (see `npm audit`). Static export still works the same (`output: 'export'` + `images.unoptimized: true` in `next.config.js`).
- `next lint` is removed in Next.js 16. Use `eslint .` directly; `eslint.config.mjs` (flat config) imports `eslint-config-next/core-web-vitals` (subpath export, no `.js` suffix) and requires ESLint 9 (peer dep of `eslint-config-next@16`).
- Raleway loads via `next/font/google` (`--font-raleway` CSS var) in `src/app/layout.tsx`, not a Google Fonts `<link>` tag.
- Design tokens (colors, radii, gradient/shine, selection color) are centralized in `tailwind.config.ts` (theme.extend) and `src/app/globals.css`.
- Next.js 16 auto-generates root `AGENTS.md` + `CLAUDE.md` (`@AGENTS.md` include) on `next dev`/`next build` with version-specific warnings — keep them committed (that's their intended use); project-specific notes were appended below the `@AGENTS.md` line in `CLAUDE.md` rather than replacing it.
