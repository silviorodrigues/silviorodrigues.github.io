---
title: Naming color tokens so juniors don't have to ask
date: 2026-06-12
tag: design systems
excerpt: If a new hire has to Slack you to know which blue to use, the naming already failed.
readMins: 4
---

Our old palette was named by hue and step — blue-500, blue-600 — which is precise and completely useless to someone deciding which blue means "this is clickable" versus "this is a link that was already visited." Precision isn't the same as clarity.

We renamed around intent instead: action.primary, text.link, text.link-visited, surface.raised. The hue-based scale still exists one layer down, for people building new components, but nobody consuming the system needs to know that blue-500 and action.primary happen to be the same value today — because next quarter they might not be.

The test I use now: hand the token list to someone who joined this week. If they can build a form without asking which color means what, the naming is doing its job.
